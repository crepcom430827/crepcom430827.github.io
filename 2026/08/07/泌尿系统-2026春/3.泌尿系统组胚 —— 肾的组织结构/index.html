一、肾的大体结构概览

1. 被膜

肾表面包裹纤维被膜。

2. 实质

分区 结构 英文
皮质 皮质迷路（cortical labyrinth） 肾小体、近/远曲小管所在区域
髓放线（medullary ray） 皮质内纵行排列的直行小管群
肾柱（renal column） 伸入髓质锥体之间的皮质组织
髓质 肾锥体（renal pyramid） 由直行小管和集合管组成
肾乳头 肾锥体尖端，开口于肾小盏

3. 组织学分叶概念

  • 肾叶（renal lobe）：一个肾锥体及其周围的皮质组织
  • 肾小叶（renal lobule）：一条髓放线及其周围的皮质迷路

4. 肾间质

结缔组织、血管、神经等构成。

二、泌尿小管系统总览

三、肾单位（Nephron）—— 肾的结构与功能单位

（一）肾小体（Renal Corpuscle）

  • 形态：圆球形
  • 组成：血管球 + 肾小囊
  • 两极：
    • 血管极（vascular pole）：入球微动脉、出球微动脉出入处
    • 尿极（urinary pole）：与近端小管曲部相连处

1. 血管球（Glomerulus）

光镜（LM）：

入球微动脉 → 反复分支形成毛细血管袢 → 逐渐汇集 → 出球微动脉

结构特征：

特征 描述
毛细血管类型 有孔型，孔径50–100 nm，基膜较厚
管径差异 入球微动脉口径 > 出球微动脉口径（维持高滤过压）
内皮表面覆盖物 富含唾液酸糖蛋白（sialoglycoprotein），带负电荷

血管系膜（Mesangium / 球内系膜）：

  • 位置：肾小球毛细血管袢之间
  • 组成：系膜细胞（mesangial cell）+ 系膜基质
  • 系膜细胞形态：不规则，突起可伸至内皮与基膜之间，甚至经内皮伸入毛细血管腔内

系膜细胞功能（高频考点）：

功能 机制/意义
合成分泌细胞外基质 维持系膜结构
产生细胞因子 参与炎症和免疫调节
吞噬和清除大分子物质 防止免疫复合物沉积（与IgA肾病、狼疮性肾炎等发病相关）
维持滤过膜完整性 结构支撑
收缩功能 调节肾小球滤过率（GFR）

Pathophysiology & Molecular Mechanism：系膜细胞表面表达多种受体（如血管紧张素II受体AT1R、血小板衍生生长因子受体PDGFR等）。AngII与AT1R结合后，通过PLC-IP₃-Ca²⁺通路引起系膜细胞收缩，减少滤过面积，从而降低GFR。在糖尿病肾病中，高糖环境激活TGF-β/Smad通路，促使系膜细胞过度合成IV型胶原和纤连蛋白，导致系膜基质扩张（mesangial expansion），这是糖尿病肾小球硬化的核心病理改变。

2. 肾小囊（Bowman’s Capsule）

层次 结构 功能
壁层 单层扁平上皮 支撑、包裹
脏层 足细胞（podocyte） 构成滤过屏障的重要组分
囊腔 壁层与脏层之间的间隙 收集原尿

足细胞（Podocyte）超微结构（EM）：

  • 相邻次级突起呈**插指状（interdigitating）**镶嵌排列
  • 突起之间的间隙 = 裂孔（slit，宽约25 nm）
  • 裂孔上覆盖裂孔膜（slit diaphragm）

Molecular Mechanism：裂孔膜的核心分子是nephrin（由_NPHS1_基因编码），与podocin（_NPHS2_基因编码）、CD2AP等形成信号复合体。Nephrin的胞外段在相邻足突间形成拉链样结构，构成裂孔膜的分子筛。_NPHS1_突变导致先天性芬兰型肾病综合征（CNF），表现为出生即有大量蛋白尿。_NPHS2_突变则导致激素抵抗型肾病综合征。这些分子的发现是理解蛋白尿发生机制的里程碑。

3. 滤过屏障（Filtration Barrier）⭐⭐⭐

三层结构（由内到外）：

层次 结构 孔径 特点
① 有孔内皮 毛细血管有孔内皮 50–100 nm 阻挡血细胞通过
② 基膜（GBM） 基底膜（富含IV型胶原、层粘连蛋白、硫酸乙酰肝素蛋白聚糖） 4–8 nm（有效滤孔） 主要的物理屏障；带负电荷
③ 裂孔膜 足细胞次级突起间的裂孔膜 ~25 nm（裂孔宽度） 最后一道屏障

双重选择性通透作用：

  • 大小屏障（size barrier）：分子直径 >4 nm 的物质难以通过；白蛋白（直径约3.6 nm）仅极微量通过
  • 电荷屏障（charge barrier）：内皮表面、基膜、足突表面和裂孔膜表面均覆盖带负电荷的唾液酸糖蛋白和硫酸乙酰肝素蛋白聚糖（HSPG），排斥带负电荷的血浆蛋白（如白蛋白，pI ≈ 4.7，生理pH下带负电）

原尿的形成：

临床联系：微小病变肾病（Minimal Change Disease, MCD）的核心病理是足突融合（foot process effacement），电荷屏障破坏，导致选择性蛋白尿（主要丢失白蛋白）。电镜下GBM正常，光镜下肾小球基本正常，故名"微小病变"。对糖皮质激素高度敏感，机制涉及T细胞功能异常分泌循环通透因子损伤足细胞。

（二）肾小管（Renal Tubule）

由单层上皮组成的小管系统。

1. 近端小管（Proximal Tubule）—— 最粗、最长，占肾小管总长的1/2

光镜（LM）特征：
特征 描述 功能意义
细胞形态 锥形或立方形 —
细胞核 大而圆，位于基部，着色浅，核仁明显 —
胞质 嗜酸性强（线粒体丰富） 高代谢活性
腔面 刷状缘（brush border） 增大重吸收面积
基底部 纵纹（basal striations） 质膜内褶+线粒体
细胞间 分界不清 侧突交错
电镜（EM）特征：
  • 微绒毛（microvilli）：密集、长，构成刷状缘
  • 质膜内褶（basal infoldings）：褶间有丰富的纵行排列线粒体（提供Na⁺-K⁺-ATPase能量）
  • 侧突（lateral interdigitations）：相邻细胞侧面突起交错
功能：
  1. 原尿重吸收的主要场所：重吸收约65–70% 的Na⁺、水、全部葡萄糖和氨基酸、大部分HCO₃⁻
  2. 分泌和排出作用：分泌H⁺、NH₃、有机酸（如对氨马尿酸PAH）、药物代谢产物（如青霉素）

Molecular Mechanism：近端小管上皮细胞腔面膜上有SGLT2（钠-葡萄糖协同转运蛋白2），负责重吸收约90%的滤过葡萄糖。这是SGLT2抑制剂（如达格列净dapagliflozin、恩格列净empagliflozin）的药理靶点——阻断SGLT2后，葡萄糖不能被重吸收，经尿排出，从而降低血糖。该类药物已被证实具有心肾保护作用（DAPA-CKD试验、EMPA-REG OUTCOME试验），机制涉及恢复管球反馈（tubuloglomerular feedback, TGF）、降低肾小球内压。

2. 细段（Thin Segment）

特征 描述
管径 最细
上皮 单层扁平上皮
功能 管壁薄，利于水和离子的被动透过

细段构成髓袢（Henle loop）的薄壁部分，在逆流倍增机制（countercurrent multiplication）中发挥关键作用：降支细段对水高度通透、对NaCl几乎不通透；升支细段对NaCl被动通透、对水不通透。

3. 远端小管（Distal Tubule）

光镜（LM）特征：
特征 描述 与近端小管的鉴别要点
上皮 单层立方上皮 细胞较小、较矮
细胞核 圆形，位于中央或近腔面 近端小管核偏基底
胞质 嗜酸性弱，色浅 近端小管嗜酸性强
腔面 无刷状缘 近端小管有刷状缘
基底部 基底纵纹明显 两者均有
管腔 较规则、较大 近端小管管腔不规则
电镜（EM）特征：
  • 微绒毛短而少
  • 基部质膜内褶发达（含丰富线粒体）
功能：
  • 重吸收水（受ADH调控）
  • 交换离子：在醛固酮（aldosterone）作用下，通过ENaC（上皮钠通道）重吸收Na⁺，分泌K⁺

近端小管 vs 远端小管 鉴别要点总结 ⭐

鉴别点 近端小管 远端小管
管径 粗 细
管腔 小而不规则 大而规则
上皮细胞 锥形/高立方，较大 立方形，较小
胞质染色 嗜酸性强 嗜酸性弱
刷状缘 有 无
基底纵纹 有 有（更明显）
细胞分界 不清 较清
核位置 偏基底 中央或近腔面
切面数量 多（管长） 少（管短）

四、集合小管（Collecting Tubule）

分段与位置

分段 位置 上皮形态
弓形集合小管 皮质迷路 立方形
皮质集合小管 沿髓放线 立方形 → 柱形
髓质集合小管 肾锥体 柱形
乳头管 肾乳头 高柱状

结构特点

  • 管径由细逐渐变粗
  • 管壁由单层立方上皮逐渐变为单层柱状上皮，至乳头管处成为高柱状上皮
  • 相邻上皮细胞分界清楚（与近端小管鉴别的重要标志）
  • 胞质着色淡而明亮
  • 细胞核圆形，位于中央，着色较深

功能

功能 机制
分泌H⁺或HCO₃⁻ 胞质内含碳酸酐酶（carbonic anhydrase）
重吸收水 受ADH（抗利尿激素/AVP）调控，通过AQP2水通道蛋白插入腔面膜
交换离子 进一步浓缩原尿

Molecular Mechanism：ADH与集合管主细胞基底侧膜上的V2受体结合 → 激活Gs蛋白 → cAMP↑ → PKA激活 → 胞质内储存的AQP2囊泡转位并插入腔面膜 → 水通透性↑ → 水重吸收↑ → 尿液浓缩。尿崩症（Diabetes Insipidus）：中枢性（ADH分泌不足）或肾源性（V2受体或AQP2基因突变）均导致集合管对水不通透，产生大量稀释尿。

五、球旁复合体（Juxtaglomerular Complex）⭐⭐⭐

位置

肾小体的血管极处

组成（三种成分）

1. 球旁细胞（Juxtaglomerular Cell, JG Cell）

项目 内容
来源 入球微动脉靠近血管极处，中膜平滑肌细胞转变为上皮样细胞
形态 立方形，胞质内含分泌颗粒（PAS阳性）
功能① 分泌肾素（renin） → 激活RAAS → 血管收缩 → 血压升高
功能② 分泌促红细胞生成因子 → 参与EPO的激活

2. 致密斑（Macula Densa）

项目 内容
位置 远端小管靠近肾小体血管极一侧
形态 上皮细胞分化形成的椭圆形斑状结构；细胞高柱状，排列紧密；核靠近腔面
功能 化学感受器——感受远端小管滤液中Na⁺浓度变化

致密斑调节机制：

临床联系：ACEI（如依那普利）和ARB（如缬沙坦）正是通过阻断RAAS的不同环节来降压和肾保护。根据KDIGO 2024 CKD指南，ACEI/ARB是合并蛋白尿的CKD患者的一线用药，可延缓肾功能恶化。

3. 球外系膜细胞（Extraglomerular Mesangial Cell）

  • 位于入球微动脉、出球微动脉和致密斑之间的三角区
  • 又称Lacis细胞或Goormaghtigh细胞
  • 功能尚未完全阐明，可能在球旁细胞与致密斑之间起信息传递作用

六、高频考点速记卡

考点 关键词
滤过屏障三层 有孔内皮 → 基膜 → 裂孔膜
滤过屏障选择性 大小屏障 + 电荷屏障（负电荷排斥）
近端小管标志 刷状缘、嗜酸性强、分界不清
远端小管标志 无刷状缘、色浅、分界较清
集合小管标志 分界清楚、胞质淡亮
球旁细胞 入球微动脉、分泌肾素
致密斑 远端小管、感受Na⁺、化学感受器
足细胞关键分子 nephrin（NPHS1）、podocin（NPHS2）
ADH作用靶点 V2受体 → AQP2 → 集合管重吸收水
SGLT2位置 近端小管腔面膜

学习建议：本节内容是泌尿系统组织学的核心，务必掌握①滤过屏障的三层结构及其分子基础；②近端小管与远端小管的光镜鉴别；③球旁复合体三种成分的位置、形态与功能。这些知识点在组胚考试中反复出现，也是理解后续肾脏病理生理和药理学的基础。
