卵巢生理

发表于2026-08-07|更新于2026-08-07|你永远是做题蛆，别忘了衡水的恩
|浏览量:

缩写说明：
E2: 雌激素
FSH：促卵泡激素
LH：黄体化激素
Gn：促性腺激素
GnRH：促性腺激素释放激素

一、卵巢的功能及周期性变化

1.1 卵巢双重功能

  • 生殖功能：产生并排出卵子
  • 内分泌功能：分泌类固醇激素（甾体）+ 肽类物质
  • 结构：分皮质（卵泡所在）与髓质

1.2 卵泡数量的动态变化（生命周期视角）

🔑 核心概念：始基卵泡是女性唯一的卵细胞储备形式，是"基本生殖单位"，可休眠数十年。卵泡储备只减不增——这是卵巢衰老不可逆的生物学根基。

1.3 卵泡发育的两阶段调控（极重要）

阶段 Gn依赖性 时间 卵泡级别
初始募集（始基→次级） 不依赖促性腺激素（自主） >9个月 静止池→生长
周期募集→成熟（次级→排卵前） 依赖促性腺激素（Gn） 85天 1-4级（持续生长期）→5-8级（指数生长期）

⚠️ 临床联系：始基卵泡的初始募集不受 FSH 调控，因此外源性 Gn（如 IVF 促排）只能"挽救"已进入 Gn 依赖窗口的窦卵泡群，无法增加卵巢总储备。这解释了为何 DOR（卵巢储备减退）患者促排效果差。

📌 通常所说的"卵泡期"仅指最后约15天的成熟阶段。

1.4 卵泡发育四阶段与受体演变（机制核心）

阶段 直径 关键组织学/受体变化
始基卵泡 0.03–0.06mm 单层梭形前颗粒细胞 + 双线期初级卵母细胞
初级卵泡 >0.06mm 颗粒细胞→单层立方；出现透明带（糖胺聚糖，卵母+颗粒细胞共同分泌）
次级卵泡 ~120μm 颗粒细胞→复层柱状(6-8层)；出现FSH-R/E2-R/T-R；分化卵泡内膜+外膜；内膜细胞出现LH-R→具备合成甾体能力
窦卵泡 500μm→ 卵泡腔形成；发生募集与选择
排卵前卵泡（Graaf） 18–23mm 颗粒细胞获得LH-R + PRL-R

1.5 募集与选择（Recruitment & Selection）

  • 募集：血清 FSH 水平及生物活性升高超过阈值 → 一组窦卵泡进入生长轨道
  • 选择：月经第7日，被募集卵泡中FSH阈值最低者对较低 FSH 仍敏感 → 优先发育为优势卵泡（dominant follicle）

🔑 FSH 阈值/窗口学说：优势卵泡通过自身高芳香化酶活性产生大量 E₂，对垂体形成负反馈使 FSH 下降；FSH 一旦降至非优势卵泡阈值以下，后者因得不到足够 FSH 支持而闭锁。这是"单卵泡排卵"的分子保障机制。

二、排卵的激素调节

2.1 E₂（雌激素） 正反馈触发 LH 峰（HPO轴核心事件）

条件：E₂ 达阈值 ≥200pg/ml 且 维持≥48小时 → 由负反馈翻转为正反馈

→ 下丘脑大量释放 GnRH → 垂体出现 LH/FSH 峰

  • LH峰是即将排卵的可靠指标：出现于卵泡破裂前 36小时，平均持续 48小时
  • 排卵前 E₂ 峰值约 300pg/ml（优势卵泡18mm时）

2.2 排卵的分子机制（多通路协同）

2.3 LH 峰对卵母细胞减数分裂的"解锁"作用（高频考点）

时点 减数分裂状态
胚胎期至排卵前 停滞于第一次减数分裂前期（双线期）
LH峰作用后 排出第一极体，完成第一次减数分裂 → 次级卵母细胞
排卵时 进入第二次减数分裂，停滞于MII中期 → 成熟卵子，具备受精能力
受精后 才完成第二次减数分裂

🔑 LH 峰还使排卵前卵泡黄素化，产生少量孕酮（这是排卵前孕酮微升的来源）。

2.4 黄体的形成与退化

  • 排卵后颗粒细胞→颗粒黄体细胞；膜细胞→膜黄体细胞
  • **排卵后7-8日（规律月经第22天）**达最大体积（1-2cm）
  • 若未受精：排卵后9-10日开始退化，功能仅维持 14-16日
  • 黄体主要分泌孕激素及部分雌激素 → 退化后形成白体

三、卵巢的内分泌功能（肽类激素重点）

3.1 多肽激素（卵巢储备评估核心）

激素 来源 作用 临床意义
抑制素 B (Inhibin B) 颗粒细胞 负反馈抑制 FSH，调节配子发育 监测性腺功能
抑制素 A 黄体 黄体期分泌 —
AMH（抗苗勒管激素） 早期（窦前/小窦）卵泡颗粒细胞 抑制始基卵泡启动募集和卵泡生长 反映卵巢储备最重要指标（不随周期波动）

🔑 机制深挖：

  • AMH 由生长卵泡分泌，构成对始基卵泡池的"刹车"，防止卵泡过快耗竭。AMH 越高 → 窦卵泡数越多 → 卵巢储备越好。其优势是周期内稳定，优于 FSH/E₂。
  • Inhibin B 在卵泡早期由颗粒细胞分泌，选择性抑制 FSH-β 合成（区别于 GnRH 同时升高 FSH/LH），是 FSH-E₂-Inhibin 三联负反馈环的关键一环。

3.2 细胞因子/生长因子

  • IL-1、TNF-α、IGF、VEGF、EGF、FGF、TGF、PDGF
  • 通过自分泌/旁分泌参与卵泡生长调节

四、性激素的合成、代谢与生理作用

4.1 甾体激素的化学本质

  • 均含环戊烷多氢菲核（甾体核），源自胆固醇
  • 分类：21碳(孕酮) / 19碳(雄激素) / 18碳(雌二醇、雌酮、雌三醇)

4.2 合成途径（Δ4 与 Δ5）

📌 关键规律：

  • 雌激素合成：排卵前经 Δ5 途径；排卵后 Δ4 和 Δ5 均有
  • 孕酮合成走 Δ4 途径
  • Δ4特点：先羟化、再裂解、脱氢；Δ5特点：先脱氢、再羟化、裂解
  • 关键酶：细胞色素P450侧链裂解酶、17α-羟化酶、3β-HSD、芳香化酶

4.3 ⭐ 两细胞-两促性腺激素学说（本章最重要的分子机制）

核心：雌激素的合成需要膜细胞与颗粒细胞、LH 与 FSH 的协同接力

两步机制详解：

  1. 卵泡膜细胞（Theca）：在 LH 刺激下，激活 17α-羟化酶/侧链裂解酶，将胆固醇 → 雄激素（雄烯二酮/睾酮）。膜细胞缺乏芳香化酶，无法自行生成雌激素。
  2. 颗粒细胞（Granulosa）：雄激素扩散穿过基底膜进入颗粒细胞，在 FSH 激活的芳香化酶作用下 → 雌二醇 E₂。颗粒细胞缺乏17α-羟化酶，无法自行生成雄激素底物。

🔑 临床联系（PCOS）：PCOS 中 LH/FSH 比值升高 → 膜细胞过度产生雄激素，而颗粒细胞芳香化不足 → 高雄激素血症 + 卵泡发育停滞。这正是"两细胞学说"的病理映射，也是来曲唑（芳香化酶抑制剂） 与FSH 促排治疗的理论基础。

4.4 各甾体激素合成部位与代谢

激素 主要合成部位 代谢产物 排泄
雌激素 颗粒细胞 E2/E1 ⇄ 互转；E3为不可逆终产物 肝代谢→葡萄糖醛酸/硫酸盐→尿(大部)+胆汁(肝肠循环)
孕激素 黄体（孕酮主要） 孕二醇 肝→尿
雄激素 雄烯二酮：卵泡内膜层(占50%)；睾酮：间质/门细胞(占25%) — 肝→尿

4.5 性激素生理作用对比

雌激素 孕激素 雄激素
生殖器 促进发育、第二性征 在E基础上进一步发育，为妊娠准备 合成雌激素的前体
子宫内膜 促增殖 限制增生→转化为分泌期 —
子宫/输卵管 促收缩、促蠕动 抑制收缩与蠕动 —
其他 阴道上皮角化、水钠潴留、保骨量 与E拮抗 维持性欲、刺激腋/阴毛、促蛋白合成与造血

🔑 雌孕激素既协同（共同促进生殖器发育）又拮抗（孕激素对抗雌激素的增殖效应）——这是子宫内膜周期性变化的激素基础。

五、下丘脑-垂体-卵巢轴（HPO轴）

5.1 轴的层级与神经内分泌本质

  • GnRH：十肽，弓状核分泌，经垂体门脉系统作用；**脉冲式分泌（间隔60-120min）**是维持 Gn 正常分泌的前提
  • 受去甲肾上腺素、多巴胺、内啡肽、5-HT、降黑素调节

🔑 GnRH 脉冲频率编码信息：高频脉冲偏向促 LH，低频偏向促 FSH。持续（非脉冲）给予 GnRH 反而抑制垂体（受体下调脱敏）——这是 GnRH 激动剂（GnRH-a）用于子宫内膜异位症、IVF 降调节的药理基础。

5.2 垂体生殖激素

TSH、HCG、FSH、LH 均为糖蛋白激素，由 α + β 亚单位组成；α亚单位序列基本相同，特异性在于β亚单位。

FSH 生理作用：

  • 促进窦前/窦卵泡颗粒细胞增殖分化
  • 激活芳香化酶 → 合成 E₂
  • 诱导颗粒细胞产生 FSH 自身受体、E受体、LH受体
  • 黄体卵泡转化期募集窦卵泡群
  • 促颗粒细胞分泌 IGF、抑制素A、激活素、卵泡抑素
  • 调节优势卵泡选择与非优势卵泡闭锁

LH 生理作用：

  • 卵泡期激活17α-羟化酶（黄体期反而抑制）
  • 刺激膜细胞合成雄激素（为E₂提供底物）
  • 排卵前 LH峰 → 卵母细胞最终成熟+排卵
  • 黄体期维持黄体功能，促孕酮、E₂、抑制素A分泌

PRL（催乳素）：

  • 198氨基酸多肽，腺垂体催乳细胞分泌，促乳汁合成
  • 受多巴胺抑制性调节
  • 垂体门脉受压 → 多巴胺运送中断 → PRL↑ → 高催乳素血症
  • PRL↑ 反馈抑制多巴胺 → 同时抑制 GnRH → Gn↓ → 排卵障碍 → 闭经泌乳综合征

5.3 反馈调节的多层级

反馈类型 含义
长反馈 卵巢性激素（主要E、P）→ 下丘脑/垂体
短反馈 垂体激素（FSH/LH）→ 下丘脑 GnRH
超短反馈 GnRH → 自身合成

5.4 ⭐ 月经周期中 HPO 轴的动态（整合记忆）

六、月经与子宫内膜周期变化

6.1 正常月经参数（临床标准）

参数 正常 异常
持续时间 4–6天 <2天 或 >7天
月经量 50–80ml >80ml
周期长度 21–35天 <21天 或 >35天
平均失铁 16mg —
  • 初潮（Menarche）：13-14岁（早11，晚16），16岁未潮需重视；通常在乳房发育2.5年后
  • 月经血不凝机制：剥脱内膜含纤溶酶原激活物 → 纤溶酶 → 分解纤维蛋白 → 血液化、不凝

6.2 子宫内膜血管系统（出血机制基础）

  • 弓形动脉 → 放射状动脉 → 基底动脉（营养基底层，不脱落）+ 螺旋动脉（营养功能层，对激素敏感、参与月经）

6.3 子宫内膜周期变化（与卵巢周期对应）

内膜期 周期日 卵巢期 激素背景 组织学要点
月经期 1–4 卵泡募集 E/P基础态 功能层脱落
增殖早期 5–7 早卵泡 E略升,FSH/LH低 内膜4-5mm,腺体短直稀疏
增殖中期 8–10 中卵泡 E渐增,FSH↓,LH略升 间质水肿最明显,腺体伸长弯曲
增殖晚期 11–14 晚卵泡 E明显升,P有上升趋势 8-10mm,假复层上皮,腺体小动脉弯曲
分泌早期 15–19 黄体早 LH峰下降支,P开始升 核下含糖原空泡(特征性)
分泌中期 20–23 黄体中 E第二高峰,P第一高峰 顶浆分泌,着床窗口
分泌晚期 24–28 黄体退化 E/P下降,FSH/LH最低后升 海绵状,10mm,螺旋动脉超内膜厚度

🔑 着床窗口（Window of Implantation）：分泌中期（约第20-23日，LH+7左右），腺体大量分泌、螺旋动脉丰富、内膜厚而松软 → 最佳着床位置。这是 IVF-ET 胚胎移植时机及子宫内膜容受性（ERA检测）的生理基础。

6.4 月经出血的形成机制

  • 止血机制：内膜塌陷血流瘀滞→血管内凝血→血小板血栓(前12h少)；24-36h脱落出血增多，PGF2α诱发血管/肌层收缩压迫止血；48h内上皮修复

⚠️ 临床联系（AUB）：当雌孕激素比例失调或孕激素缺乏时（如无排卵周期），内膜脱落不同步、不完整 → 异常子宫出血（AUB-O）。这是无排卵性 AUB 的核心机制。

器官 卵泡期（雌激素主导） 黄体期（孕激素主导）
宫颈黏液 稀薄透明,拉丝度>10cm,羊齿状结晶,利于精子上游 黏稠,椭圆体,精子难上游
阴道上皮 底层细胞成熟为富糖原表层细胞,抑菌+精子获能 表层细胞堆积皱褶脱落→角化前细胞,利于自净

其他内分泌腺影响

  • 甲状腺：亢进/不足均致月经异常、生育力下降
  • 肾上腺：女性雄激素主要来源；过多→多毛、肥胖、痤疮
  • 胰腺：胰岛素抵抗/高胰岛素血症 → 促卵巢产雄激素（PCOS核心环节）
  • 前列腺素：PGF2α 促螺旋动脉收缩→内膜脱落；与原发性痛经相关

📌 青春期成人宫体:宫颈=2:1（与儿童期1:2相反）。

九、子宫内膜激素受体（了解）

9.1 受体类型

  • 雌激素受体（ER）：核受体 ERα/ERβ + 膜受体 GPER/GPER1
    • 正常内膜中 ERα 为主；子宫内膜异位症中 ERβ、GPER 重要
    • 增殖期 ER 表达增加，分泌期明显减少
  • 孕激素受体（PR）：核受体 PR-A/PR-B（基因组效应）+ 膜受体 mPRs（非基因组效应）
  • 受体结构：6个功能域（NTD/AF-1、DBD、铰链、LBD/AF-2）

9.2 雌激素作用机制（4类）

  1. 直接基因组：E-ER复合体二聚化→入核→结合ERE→转录
  2. 间接基因组：膜受体→第二信使级联/离子通道/转录因子
  3. ER非依赖：抗氧化效应
  4. 配体非依赖：无需E的基因组事件

9.3 子宫内膜生化变化

  • 透明质酸（HA）：增生中期利增殖,分泌中期利着床
  • 水解酶：溶酶体内储存,E/P↓时溶酶体膜通透性↑→水解酶释放→内膜剥脱出血
  • 血管收缩因子：内皮素-1(收缩螺旋动脉)+ PGF2α(收缩肌层)→功能层缺血坏死脱落
